# Portfolio Project

This project is a personal portfolio website built using HTML and Tailwind CSS.

## Description

It showcases personal information, skills, and selected projects in a clean and responsive layout.

## Technologies Used

- HTML5
- Tailwind CSS (CDN)
- Google Fonts
- BoxIcons

## Features

- Responsive navigation bar
- Hero section with introduction
- Skills showcase
- Project showcase with GitHub links
- Biography and social media links
- Contact section (UI only)

## Installation

1. Clone this repository:
   ```bash
   git clone https://github.com/bamamaulanaw/portfolio-project.git
   ```

2. Open `index.html` in your browser.

## Usage

This website can be used as a personal portfolio and deployed on static hosting services such as GitHub Pages.
